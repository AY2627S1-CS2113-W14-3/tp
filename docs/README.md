# WhatsCooking

WhatsCooking is a recipe manager for home cooks who prefer typing to clicking. Store recipes with their
ingredients, steps and notes, find them quickly, resize them for a different number of servings, see possible
allergens and ingredient alternatives, and keep track of the ingredients you have at home, all from a
command-line interface.
