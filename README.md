# What's Cooking

What's Cooking is a command-line recipe manager for home cooks. Store recipes with their ingredients, steps
and notes, search them, scale them to a different number of servings, check possible allergens, and track
the ingredients you have at home.

* [Developer Guide](https://ay2627s1-cs2113-w14-3.github.io/tp/DeveloperGuide.html)

## Running the app

1. Install Java 25.
1. Download `whatscooking.jar` from the [releases page](https://github.com/AY2627S1-CS2113-W14-3/tp/releases).
1. In a terminal opened in the jar's folder, run `java -jar whatscooking.jar`.

## Setting up for development

Prerequisites: JDK 25 and the latest IntelliJ IDEA.

1. Import the project into IntelliJ **as a Gradle project**
   ([guide](https://se-education.org/guides/tutorials/intellijImportGradleProject.html)).
1. Run `src/main/java/seedu/whatscooking/WhatsCooking.java` to start the app.
1. Run the tests with `gradlew.bat test` (Windows) or `./gradlew test` (macOS/Linux), and the text UI tests
   with the `runtest` script in `text-ui-test`.
